Manual Text

1) Overview & Roles

Infinite Aura supports account management and collaboration between parties (Guardian / Center / Trainer / Administration). Some features are shown based on the account role.

Guardian Center Trainer Admin / Sub-admin

Important

Center accounts use an internal verification workflow: verification status can be: pending review / approved / rejected. If rejected, the system may allow re-uploading documents depending on admin settings.

2) Requirements & Permissions
  1. Install the app on Android.
  2. Select the app language (Arabic / English / Spanish / French / Hindi / Chinese).
  3. Permissions may appear based on what you use:
    • Notifications: to receive booking updates.
    • Location (Centers): to auto-fill a Google Maps link when creating a public listing.
When do I need location permission?

Only if you tap Use current location in the public center page to auto-generate a Google Maps link. You can also paste a Maps link manually without granting permission.

3) Create an Account

From the Register screen

  1. Open Create Account.
  2. Enter the basics:
    • Name (guardian name or center name depending on account type).
    • Email address.
    • Password.
    • Select Country / Country code (important for centers).
  3. Select account type:
    • Guardian.
    • Center — requires verification documents (see section 3-B).
  4. Complete Email OTP verification first (see section 3-A).
  5. After OTP succeeds, tap Register to finish creating the account.
Note

The app prevents completing registration if OTP verification is not done (Register stays disabled until OTP succeeds).

3-A) Email OTP Verification (Used in Register & Login)

The system uses a 6-digit OTP code sent to your email. The same OTP concept is also used before login (extra security).

  1. Enter your email correctly.
  2. Tap Send OTP.
  3. Check your email (Inbox / Spam) for a 6-digit code.
  4. An OTP dialog appears (e.g., Email Verification):
    • Enter the 6-digit code.
    • Tap Verify.
    • If wrong/expired: you may see a message like “Invalid or expired code”.
  5. On success: the dialog closes and verification is considered complete.
Common OTP issues
  • Code not received: wait a minute, check Spam, and confirm the email is correct.
  • Code doesn’t work: resend and use the latest code only.
  • Don’t close the OTP dialog before verifying, otherwise the process is cancelled.
3-B) Center Verification Documents (Centers only)

When you choose Center account type, the app asks you to upload documents proving the center’s legitimacy. Admin/Sub-admin review these documents to approve or reject.

  1. On the register screen, after selecting Center, you will see Center Verification Documents.
  2. Tap upload and select files from your device.
  3. Constraints implemented in the app:
    • Accepted types are typically: PDF / images (depending on your file picker).
    • Maximum size: 50 MB per file.
  4. After selecting: a list of chosen/uploaded files appears.
  5. Finish registration after OTP succeeds.
Warning

If center document upload fails during registration, the system may cancel/delete the new account to avoid creating a center without documents.

4) Login & Password Reset

Login OTP before login

  1. Open Login.
  2. Enter email and password.
  3. Before signing in, Email OTP starts:
    • A code is sent to your email.
    • Enter the code in the dialog and verify.
  4. After OTP success, the app signs you in with email/password.
Forgot password?
  1. On the login screen choose Forgot password.
  2. Enter your email.
  3. You’ll receive a reset email.

(Password reset is handled via Firebase Auth.)

5-A) Create a new session

The New Session screen is used to create an assessment session within the system. The result depends on three parts: Photo analysis, Questionnaire, and Activities. After running the analysis, the session is saved and the results screen opens.

Photo analysis Questionnaire Activities Analyze then save

How do I reach this screen? From the individual details screen, choose Start a new session.

First: Add a session photo (Required)

  1. Tap the Select photo option.
  2. Choose the source: Camera or Gallery.
  3. The photo is checked to detect a face; if no face is detected, you must choose another photo or take a clearer one.

Second: Select the photo context

  1. The photo context is a description of the individual’s state at the moment the photo is taken only, not a permanent evaluation.
  2. Select one value based on the behavior shown during photographing.
  3. Meanings of the options:
    • Normal: Normal cooperation, with no clear fear or clear refusal, even if facial expressions are neutral.
    • Shy: Shyness or avoiding looking at the camera while generally remaining cooperative.
    • Fear: Clear signs of fear during photographing such as severe tension, crying, strong distress, or trying to move away due to fear.
    • Unwilling to respond: Clear refusal of photographing or resistance such as turning the face/phone away, covering the face with a hand, or not allowing the photo to be taken.
  4. If the state is unclear, choose Normal.
  5. The app may automatically restrict some options if they conflict with the photo analysis results (according to the system’s validation logic).

Third: Fill in the questionnaire

  1. Select an answer for the questions with scores from 1 to 5.
  2. Basic requirement: You must answer at least one question before running the analysis.
  3. Completing all questions gives a more accurate result.

Fourth: Add activities to the session (Required)

  1. From the Activities section, choose at least one activity.
  2. For each activity, enter repeats/day to be 1 or more.
  3. Optional notes can be added for the activity.
  4. Basic requirement: The analysis cannot be run unless at least one activity is selected with repeats/day (≥ 1).

Fifth: Run the analysis

  1. Tap the Analyze button.
  2. The following values are calculated:
    • Photo score (0–100)
    • Questionnaire score (0–100)
    • Activities score (0–100)
    • Overall score (0–100)

Sixth: (Depending on account type) Add therapies to the session

  1. The Therapies section may appear only for accounts authorized within the system.
  2. When enabling a therapy within the session, you can enter:
    • Goal (Optional)
    • Notes (Optional)
    • Effectiveness (1–5) required when selecting the therapy to indicate how effective it is

Finally: Save the session and open the results

  1. After the analysis succeeds, tap Save.
  2. The session is saved with the main result fields, in addition to:
  3. After saving, the current sessions for the individual screen opens directly.
5-B) Session results

The Session Results screen shows the session details after saving: scores, photo data (if available), and questionnaire answers, in addition to activities (and therapies may appear depending on what was added within the session). The data here is for viewing, and the results of a saved session are not edited from the results screen.

Overall score Score details Questionnaire Activities

How do I open session results?

  1. Open Individual details.
  2. From the Sessions list, select the required session.
  3. The Session Results screen opens.

Content shown within the results

  1. Session summary: date and time and a quick summary.
  2. Scores (0–100):
    • Photo score
    • Questionnaire score
    • Activities score
    • Overall score with the weights used in the system (photo analysis 0.35, questionnaire 0.35, activities 0.30).
  3. Activities:
    • Show the list of activities added to the session.
    • Show the number of activities and total repeats when available.
  4. Questionnaire:
    • Show questionnaire answers with values 1–5 for viewing only.
  5. Therapies (if added in the session):
    • Therapy items appear with the goal, notes, and effectiveness if they were added.
When might the session photo not appear?
  • The session may be saved without a viewable photo.
  • There may be a delay while loading/decoding the photo depending on the system’s protection mechanism.
  • Permission to view the content may not be available for the current account depending on sharing and permission logic.
Linking results with other screens Session results are linked to the sessions list in the individual details, and are included in performance calculations and reports according to account permissions.
5-C) Guardian: Centers Directory & Send a Booking Request

Centers Directory Booking requests

  1. Open Centers Directory.
  2. Select a country and use search to filter results.
  3. You will see center cards with published data (description/address/phone/links/maps… as provided by the center).
  4. Tap Contact to see options:
    • Call
    • Location (if available)
    • Open Google Maps
  5. To send a booking request: tap Booking Request on the center card.
  6. Fill the request:
    • Preferred time: choose date then time.
    • Duration: 30 / 45 / 60 / 90 / 120 minutes.
    • Message: describe what you need.
  7. Tap Send. The request becomes Pending.
5-D) Guardian: Track Bookings & Respond to Reschedule

My bookings Needs action

  1. Open My Bookings.
  2. Main tabs:
    • Pending: waiting for the center’s response.
    • Needs action: the center proposed a new time and needs your response.
    • Approved: confirmed appointments.
  3. Inside Needs action:
    • Review the proposed time and previous time (if shown).
    • Tap Accept to approve the new time.
    • Or tap Decline to reject it.
Quick status meanings
  • pending: waiting for center response
  • approved: confirmed appointment
  • rejected: rejected (a reason may appear)
  • rescheduled: center proposed a new time (your action needed)
6) Center: Center Management & Archive

Center Management is used to share items from the center account (such as Individuals and Therapies) with other accounts by email (Guardian / Trainer / etc.). It also includes a direct button to open the Archive.

Sharing targets Individuals Therapies Archive

How do I reach this screen?

From a Center account: open Profile then under Center Tools choose Center Management. You can also open it from the home shortcuts (if available).

1) Add a sharing target (email)

  1. At the top, find Share with accounts.
  2. Enter the target email.
  3. (Optional) Enter a name for easier recognition.
  4. Select User type: Guardian / Trainer / Center / Other
  5. Tap Save to store it in the Sharing targets list.
Important note about “selecting a sharing target”

When you tap a target in Sharing targets, it becomes selected. The app uses the selected target to indicate which items are already shared. This is most accurate when only one target is selected.

2) Search & filters inside Center Management

  1. Use Search to type an individual/therapy name or an email/name.
  2. Choose where to search:
    • Individuals
    • Therapies
    • Emails / Accounts
  3. To clear search, use the clear button in the search field.

3) Share individuals/therapies with the selected target

  1. Select a target from Sharing targets.
  2. Select individuals via checkboxes.
  3. Select therapies via checkboxes.
  4. Tap Share selected.
  5. After sharing:
    • You may see a 🔗 icon on shared items.
    • You may see Already shared when one target is selected.
Two required conditions before sharing/unsharing
  • You must select a sharing target first.
  • You must select at least one individual or therapy.

4) Unshare (remove sharing)

  1. Select the same target (email).
  2. Select the individuals/therapies to unshare.
  3. Tap Unshare selected.

5) Archive link from Center Management

At the bottom of Center Management there is an Archive button that opens the center’s archive screen.

  1. Tap Archive (archive icon).
  2. You go to Center Archive, which shows archived individuals/items.
  3. Tap an archived item to open details and view archived sessions.
  4. Inside an archived session you may see Restore to move it back to the original individual record.
  5. You can also delete an archive item from the list using the delete button (🗑️).
What does “Restore session” mean in the archive?

Restore moves the archived session from the archive path back to the original individual record (based on IDs saved in the archive document), so it appears again under the individual’s sessions.

6-A) Center: Public Listing (Publish/Hide in Centers Directory)

Public center page Published

  1. Open Public Center Page.
  2. Fill the required fields:
    • Work days: select working days.
    • Work hours: e.g., 9:00 AM - 5:00 PM.
    • Address: city/area/street…
    • Description: brief services overview.
    • Phone: contact number (prefer international format).
    • Google Maps link: required here.
    • Website: optional (must be valid http/https).
  3. Auto-fill Maps link:
    • Tap Use current location.
    • Allow location permission if requested.
    • A Maps link is generated using coordinate search.
  4. Save options:
    • Publish: show the center in the directory.
    • Save as draft: save without publishing (hidden).
    • Hide: unpublish (remove from directory).
Note

Listing status (Published / Hidden) appears at the top of the screen, and you can update data even while published.

7) Center: Booking Management (Approve / Reject / Reschedule)

Booking management Requests

  1. Open Booking Management.
  2. You will see tabs:
    • Requests: new requests or reschedule requests awaiting guardian response.
    • Schedule: approved bookings ordered by appointment time.
  3. In Requests:
    • Open a request to view details (sender/message/preferred time/duration).
    • Choose an action:
      • Approve: select final date/time + duration, then confirm.
      • Reschedule: propose a new time (guardian must accept/decline).
      • Reject: provide a reason and confirm.
  4. In Schedule:
    • Confirmed appointments appear with time and duration.
    • You can also Reschedule from the schedule tab (propose a new time).
What happens on “Reschedule”?

The center proposes a new time, the booking becomes rescheduled, and the guardian must accept or decline from the Needs action tab.

8) Center: Performance Screen

Performance Analytics

  1. Open Center Performance.
  2. You will see summary cards such as:
    • Center performance score (0–100).
    • Total individuals.
    • Total sessions (and sessions in last 30/90 days).
    • Upcoming sessions within 7 days.
    • Individuals with no sessions, or no upcoming session.
  3. Change the time filter (All / Last 30 / Last 90) to view a subset of data.
9) Center: Archive

Archive Archived individuals

You can reach Archive directly from Center Management using the archive button.

  1. Open Archive.
  2. You will see a list of archived individuals (if any).
  3. Each item shows:
    • Individual name (if saved in archive data).
    • Who it was archived from (name/email if available).
    • Archive date.
  4. Actions:
    • Tap an item to open archived sessions for that individual.
    • Delete (🗑️) removes the archive document from the list.
Restore a session from the archive

The project includes logic to restore an archived session back under the original individual (copying session data and answers depending on the storage/encryption implementation).

10) Admin: Center Requests & Verification

The Admin account in Infinite Aura is responsible for reviewing new center registrations and controlling a center account status (approve / reject / freeze / request document re-upload) to ensure published centers are trustworthy.

Admin panel Verification Approve / Freeze Reject

How do I reach this screen?

From an Admin account: open the admin dashboard and go to Centers Management.

1) Center states in the project

  • verification_status:
    • pending: new center awaiting review
    • approved: verified and allowed to publish/receive bookings
    • rejected: rejected (may be allowed to re-upload)
  • account_status:
    • active: account is active
    • frozen: access is restricted until unfreezed

2) Review a new center

  1. Open the Pending filter/tab.
  2. Tap a center card to open details.
  3. Review:
    • Center name, email, country
    • Uploaded verification documents
Main admin actions
  • Approve: set verification to approved.
  • Reject: set verification to rejected and optionally store a reason.
  • Request re-upload: ask the center to upload updated verification documents.

3) Freeze / Unfreeze a center

  1. From the center card/details, tap Freeze.
  2. The account_status becomes frozen.
  3. To restore access, tap Unfreeze so it returns to active.
When should I freeze instead of reject?
  • Reject: typically during initial review when docs are invalid/missing.
  • Freeze: a temporary restriction after the account was already active.

4) How admin decisions affect users

  • An approved center can publish its listing and receive bookings.
  • A rejected center may see a rejection screen and re-upload instructions (if enabled).
  • A frozen center may be redirected to a frozen screen and blocked from actions until unfrozen.
11) Sub-admin: Country-based Center Management

The Sub-admin role has a similar purpose to Admin (review centers and take actions), but with permissions restricted to a specific country. Sub-admin only sees and manages centers in their assigned country.

Sub-admin Country-scoped Approve / Freeze Limited access

Permissions principle

The sub-admin’s country is stored in the sub-admin account. Based on it, only centers in the same country are visible and manageable.

1) What can a sub-admin do?

  • View centers in their country (Pending / Approved / Rejected / Frozen using filters).
  • Open center details and review verification documents.
  • Perform:
    • Approve
    • Reject with reason
    • Freeze / Unfreeze
    • Request document re-upload

2) What can a sub-admin NOT do?

  • Manage centers outside their country.
  • Assign admin roles or change other sub-admin permissions (admin-only).

3) Steps to review a center (sub-admin workflow)

  1. Open the centers management screen in the Sub-admin account.
  2. Use the Pending filter to view new center requests in your country.
  3. Open a center and review documents.
  4. Choose an action:
    • Approve if documents are valid.
    • Reject with a reason if something is missing/invalid.
    • Request re-upload if the center only needs updated files.
  5. If needed, use Freeze for a temporary restriction.
How do sub-admin decisions appear to the center?
  • Updates to verification_status and/or account_status show immediately after sync.
  • On re-upload request, the center sees instructions and can submit new documents.
Professional tip

Write clear reasons (e.g., “License not readable” / “Missing document”) to speed up fixes and reduce support back-and-forth.

12) Notifications

The app uses notifications (Firebase + local notifications) for: booking updates and (depending on enabled features) session scheduling/reminders.

  1. On first use, notification permission may be requested.
  2. If you disabled notifications in the system:
    • Open phone Settings > Apps > Infinite Aura > Notifications, and enable them again.
Open app notification settings directly

The project includes logic to open the system notification settings screen directly from inside the app (especially on Android).

13) Quick Fixes & Support

Common issues

  • OTP not received: check Spam, use the latest code, confirm the email is correct.
  • Booking not showing for the guardian: refresh the screen, ensure you are signed in, and allow time for sync.
  • Invalid Maps link: use “Use current location” or paste a valid http/https Google Maps link.
  • No notifications: enable notification permission in system settings, then reopen the app.
